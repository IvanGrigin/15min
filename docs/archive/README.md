# Архив документации

Здесь лежат документы, которые **выполнили свою роль и больше не описывают
текущее состояние**. Они не удалены: по ним видно, как принимались решения,
и в них остались номера задач и замеры, на которые ссылаются старые отчёты.

Правило: файл попадает сюда, когда у него появился преемник или когда
описанная работа завершена. В первой строке каждого файла — пометка,
чем он заменён.

| Файл | Почему в архиве |
|---|---|
| `COVERAGE_PLAN_60.md`, `COVERAGE_PLAN_75.md`, `COVERAGE_PLAN_90.md` | планы по вехам покрытия; заменены `docs/CORPUS_V2_BATCH_PLAN.md`, где работа разложена по батчам, а не по процентам |
| `TRIAL_TASK_CALENDAR.md` | пробное задание для агента; батч «Календарь» давно перенесён |
| `UNIVERSE_STORY_RECONCILIATION.md` | разовая сверка реестров от 2026-07-29; расхождения устранены тогда же |
| `CLEAN_CORPUS_2026.md` | первый подход к чистому корпусу; заменён `docs/all_tasks_all_files_v2.md`, где каждый номер — задача |
| `UNCOVERED_TASK_GROUPS.md` | разбор непокрытого по старому своду с OCR-мусором; заменён `docs/CORPUS_V2_UNCOVERED_PLAN.md` по корпусу v2 |

Что **не** архивируется и почему:

- `HARVEST_FROM_LEGACY_AUDIT.md` — каталог известных дефектов исходных задач,
  на него ссылаются `notes` четырёх шаблонов;
- `UNIVERSE_STORY_INTEGRATION.md` — описание живого сюжетного слоя;
- `module_29a_regular_human_names.md`, `approved_dimensions_150_characters.md` —
  справочные данные, а не инструкции;
- `docs/all_tasks_all_files.md` и `docs/NN_*.md` — неизменяемый корпус,
  на его номера ссылаются `source_metadata` шаблонов.
