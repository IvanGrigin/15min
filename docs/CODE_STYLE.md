# Единый стиль кода и имён

Одно правило на каждый вопрос — чтобы в репозитории не появлялось три написания
одного и того же. Проверяется автоматически: `tests/test_code_style.py`.

## 1. Имена файлов и каталогов

| Что | Правило | Пример |
|---|---|---|
| Каталоги | только строчные, `snake_case` | `docs/`, `template_studio/`, `problem_sets/` |
| Модули Python | только строчные, `snake_case` | `declension_rules.py`, `studio_site.py` |
| Файлы данных JSON | только строчные, `snake_case` | `russian_nouns.json`, `approved_characters.json` |
| Шаблоны задач | строчные, совпадают с `template_id` | `process_circle_overlay.json` |
| Документы-руководства | `UPPER_SNAKE_CASE.md` | `AGENT_TASK_TO_TEMPLATE_PROMPT.md` |
| Файлы корпуса | как есть в источнике | `14_chislovye_protsessy_….md` |
| Корневые файлы | общепринятые заглавные | `README.md`, `AGENTS.md`, `LICENSE` |

**Каталог документации называется `docs`, строчными.** Ни `Docs`, ни `DOCS`.
Это важнее, чем кажется: macOS не различает регистр в путях, а Linux и git —
различают. Написанный с заглавной путь работает на ноутбуке и ломается
на сервере, причём молча.

## 2. Язык

| Что | Язык |
|---|---|
| Имена переменных, функций, классов, полей JSON | английский |
| Докстринги | **русский** |
| Комментарии | **русский** |
| Тексты ошибок, которые видит человек | **русский** |
| Сообщения в консоль | **русский** |

Причина: код читают и пишут русскоязычные агенты и разработчики, а предметная
область — русская морфология. Объяснение «почему тут родительный падеж»
на английском теряет половину смысла.

Идентификаторы при этом английские: смешивать кириллицу в код не нужно,
а `падеж = "gen"` ломает автодополнение и грепы.

## 3. Докстринги

Публичная функция, класс или метод (имя не начинается с `_`) **обязаны** иметь
докстринг на русском. Приватные — по желанию, но если логика неочевидна,
лучше написать.

Первая строка — одно предложение в изъявительном наклонении, что делает функция:

```python
def locations_of(universe: str) -> tuple[Location, ...]:
    """Вернуть локации вселенной с полной падежной парадигмой."""
```

Если есть неочевидное «почему» — оно идёт после пустой строки. Именно там
место знанию, которое иначе теряется:

```python
def _s_or_so(instrumental: str) -> str:
    """Выбрать предлог «с» или «со» перед творительным падежом.

    «со» ставится перед стечением согласных, начинающимся на с, з, ш, ж:
    со Свеном, со шляпой, но с Нюшей. Правило работает на форму, а не
    на лемму, поэтому живёт рядом с рендером.
    """
```

Не пишите докстринг, пересказывающий сигнатуру: «принимает строку, возвращает
строку» — это шум. Пишите то, чего в сигнатуре нет.

## 4. Комментарии

Комментарий объясняет **почему**, а не **что**. «Что» видно из кода.

```python
# Плохо: увеличиваем счётчик на единицу
attempts += 1

# Хорошо: температура растёт с попытками — на 0.2 модель дословно
# воспроизводит предыдущий ответ, и цикл исправлений не сдвигается.
temperature = min(0.2 + 0.2 * (attempt - 1), 0.8)
```

Отдельно ценны комментарии-предупреждения для следующего агента: если место
выглядит как ошибка, но таковой не является, это надо написать прямо.

## 5. Оформление Python

- Отступ 4 пробела, длина строки до 110 символов.
- `from __future__ import annotations` первой строкой после докстринга модуля.
- Аннотации типов у всех публичных функций.
- Импорты: стандартная библиотека, пустая строка, свои модули.
- Никаких однострочных функций через `;` — это стиль архивного кода,
  повторять его не нужно.
- Кавычки двойные.

## 6. Тексты для человека

Сообщения об ошибках говорят, **что не так и что сделать**:

```python
raise TemplateRuntimeError(
    f"Параметр {name}: слова {lemma!r} нет в data/language/nouns/russian_nouns.json."
)
```

В русских текстах — русская типографика: «ёлочки» для кавычек, тире `—`,
буква ё там, где она есть в слове. Числа с единицами пишет движок,
руками их склеивать не нужно.

## 7. Что проверяется автоматически

`tests/test_code_style.py`:

- имена каталогов и Python-модулей — строчные `snake_case`;
- каталог документации существует ровно в одном написании;
- у публичных функций и классов есть докстринг;
- докстринги и комментарии содержат кириллицу, а не английский;
- нет однострочников через `;`.

Тест — не бюрократия, а защита от расползания: правило, которое не проверяется,
через месяц перестаёт соблюдаться.
