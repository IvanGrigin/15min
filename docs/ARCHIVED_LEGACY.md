## Почему закрыто

### 1. Падежи невозможно починить точечно

Текст задачи жил в f-строках Python. Имя персонажа подставлялось всегда
в именительном падеже, независимо от того, какой падеж требует фраза:

```python
text = f"{a.name} идёт впереди {b.name}; ... Через сколько минут {b.name} догонит {a.name}?"
```

На выходе: «Хэмм идёт впереди **Базз Лайтер**… **Базз Лайтер** догонит **Хэмм**».
Нужно «впереди Базза Лайтера», «догонит Хэмма». Род глагола тоже терялся:
«**Даша купил** товар», «**Анна купил** товар».

Чинить это пришлось бы в каждой из сотен f-строк отдельно, и следующий
добавленный шаблон ломал бы всё заново — компилятор такое не ловит.

### 2. Род определялся эвристикой по последней букве

```python
if name.endswith(("а", "я")): return "feminine"
```

Из 150 персонажей минимум 15 определялись неверно: Чебурашка, Незнайка,
Муфаса, Симба, Йода, Кузя, Пумба, Царь-батюшка, галчонок Хватайка, ослик Иа-Иа.

### 3. Обходной путь закреплялся тестами

Там, где падежи мешали, фразу ломали: вместо «Эльза старше Кроша» писали
«Персонажи: Эльза и Крош. Возраст старшего…». Это было зафиксировано тестом,
то есть канцелярит стал требованием.

### 4. Каждый новый шаблон стоил Python-кода

Функция-стратегия, запись в `STRATEGIES`, запись в `templates.json`, правка
`source_accounting.json`, ветка в `if`-цепочке сайта, тест. 7195 строк
в 33 файлах — часть из них ужата в однострочники, потому что объём стал
неуправляемым.

### 5. Архив из PDF не масштабировался по качеству

В `All_tasks_templates.json` слоты бывают только двух типов: `integer` (3744)
и `time` (214). Ни одного слота под слово. Числа менялись, а согласование
оставалось от оригинала: «5 яблока», «21 монет».

## Чем заменено

| Было | Стало |
|---|---|
| f-строка в Python | текст со слотами в JSON: `{hero:gen}`, `{item:count,n}` |
| род по последней букве | явный род в реестре из 271 персонажа |
| имя только в именительном | шесть падежей полного имени: «кота Матроскина» |
| предлог в тексте руками | `{place:loc}` / `{place:dir}` / `{hero:with}` — предлог из данных |
| новый шаблон = новый Python | новый шаблон = один JSON-файл, ноль строк Python |
| сайт с ветвлением на 35 модулей | `problemgen/web/studio_site.py`, темы берутся из библиотеки |
