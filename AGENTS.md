# AGENTS.md

Обязательные правила для любого агента, работающего в этом репозитории.
Читается целиком перед первым изменением.

## Главный принцип

**Python решает задачу. JSON её формулирует.**

Одна задача — одна JSON-запись в `data/template_studio/library/`. Из неё
генератор без нейросети собирает бесконечно много корректных по-русски
вариантов с автоматически посчитанным ответом.

Генерация детерминированная и проверяемая: LLM не участвует в момент выдачи
задачи ученику. Модель может помогать человеку разбирать исходную задачу,
но её результат обязан пройти валидацию без неё.

## Что запрещено

1. **Писать Python-генераторы задач.** Никаких f-строк с текстом условия,
   никаких новых модулей вида `*_templates.py`, никаких веток «если модуль X».
2. **Хранить в коде** текст условия, имена персонажей, названия предметов
   или их словоформы. Всё это — данные.
3. **Восстанавливать архивный стек** или копировать из него код.
   См. `docs/ARCHIVED_LEGACY.md`: направление закрыто, а не приостановлено.
4. **Ослаблять валидацию**, чтобы шаблон прошёл. Не проходит — виноват шаблон.
5. **Автоматически склонять слова в рантайме.** Все формы задаются явно
   в данных. Правила склонения (`scripts/declension_rules.py`) — инструмент
   подготовки данных, а не часть движка.
6. **Писать в шаблоне то, что зависит от мира.** Глагол движения, единицу
   скорости, название денег, предлог перед городом, как зовут обитателей —
   всё это данные. Если в тексте шаблона появились «шёл», «км/ч», «монета»,
   «в город Чита» или «пираты» леммой — слой подобран неверно: получится
   «Джек Воробей шёл со скоростью 6 км/ч», «Молния Маккуин идёт 3 км/ч»
   и одна и та же очередь за похлёбкой во всех 116 вселенных.
7. **Отступать от единого стиля.** Каталоги и модули — строчными, докстринги
   и комментарии — по-русски: `docs/CODE_STYLE.md`, проверяется
   тестом `tests/test_code_style.py`.

## Что разрешено и ожидаемо

- Добавлять JSON: шаблоны задач, персонажей, локации, существительные.
- Писать одноразовые исследовательские скрипты в `/tmp` (в репозиторий не кладём).
- Писать **тест с независимым решателем** — единственное место, где Python
  имеет право знать математику задачи. Решатель обязан решать задачу заново
  по её условию, а не повторять формулу шаблона.
- Расширять движок, если не хватает **общей** возможности (новый падежный слот,
  новый тип параметра). Не «логика конкретной задачи», а операция для всех.

## Порядок работы над задачей

Полный алгоритм из 13 шагов — `docs/AGENT_TASK_TO_TEMPLATE_PROMPT.md`.
Коротко: разобрать математику руками → проверить осмысленность по всему
диапазону → измерить долю годных наборов (порог 5 %) → добрать недостающие
данные → написать текст со слотами → constraints по чек-листу → прочитать
десять примеров глазами → тест-решатель → публикация → журнал.

Батч — **12–15 задач корпуса**, не меньше. Прежде чем написать первую строку,
приходится прочитать почти 900 строк правил; на четырёх записях эта плата
не окупается. Если задач в теме меньше — добирайте из соседней.

После батча: полный прогон тестов, обновление журнала, отчёт. В отчёте
обязательна строка «изменения в Python» — если там что-то, кроме «нет»,
это должна быть общая возможность движка, а не логика задачи.

## Слои мира: что откуда берётся

Вселенных 116, персонажей 710. Они бесполезны, если шаблон зашивает слово
леммой. Перед тем как написать `"lemma": "..."`, проверьте, нет ли для этого
слоя:

| Нужно в тексте | Как берётся | Пример |
|---|---|---|
| персонаж | `{"type": "character"}` | Джек Воробей, Пикачу |
| ровесник персонажа | `"same_age_class_as": "a"` | не «мама Свинка старше бабушки Свинки» |
| попутчик того же способа | `"same_motion_as": "a"` | оба плывут, а не «один ползёт, другой летит» |
| место | `{"type": "location"}`, слоты `{p:loc}` / `{p:dir}` | в Хогвартсе, на пляже |
| город или планета | `{"type": "toponym"}`, слоты `{c:loc}` / `{c:dir}` / `{c:from}` | в Читу, с Камчатки, на Татуине |
| предмет мира | `"from_universe_items": true` | бластер в «Звёздных войнах», самовар в Простоквашино |
| предмет нужного класса | `+ "tags": ["food"], "fallback_lemmas": [...]` | «съели» требует еды: «съели 108 факелов» — не задача |
| деньги мира | `"from_universe_currency": true` | дублоны, кредиты, галлеоны |
| ценность мира | `"from_universe_valuables": true` | кайбер-кристаллы, жёлуди |
| **обитатели мира** | `"from_universe_folk": true` | штурмовики, гонщики, хоббиты, эмоции |
| **чем различаются группы** | `{"type": "trait_scale", "agrees_with": "folk"}`, слоты `{t:one}`…`{t:three_pl}` | красные / синие / зелёные; маленькие / средние / большие |
| глагол движения | `{hero:move,past}` | плыл, ехала, полз |
| единица скорости | `{hero:speed_phrase}` | км/ч, узлов, км/с |
| число ног существа | `{"type": "noun_trait", "of": "a", "trait": "legs"}` | 2 у курицы, 8 у паука |
| отбор существ | `"tags": ["farm"]`, `"legs": [4]` | на ферме не бывает тигров |
| время на табло | `{value:clock}` | 04:00, а не 4:0 |

Правило простое: **если слово меняется от мира к миру — это данные.**
Толпа в задаче про очередь, класс или турнир берётся через `from_universe_folk`,
иначе во всех мирах будут стоять пираты.

То же касается сюжетных деталей, которые не обязаны быть именно такими.
Очередь не обязана стоять за похлёбкой, а группы не обязаны различаться
возрастом: за чем очередь — предмет мира, чем различаются группы — шкала
признаков. Проверка простая: **если в тексте шаблона стоит слово, которое
можно заменить другим без вреда для математики, оно должно быть слотом.**
Один шаблон «очередь из трёх групп» даёт 97 вселенных, 48 слов для толпы,
6 шкал признаков и 94 предмета — это и есть смысл всех добавленных миров.

**Заполняя данные мира, не отделывайтесь общим словом.** «Житель» подходит
любому миру и потому не говорит ни о чём: в Тачках очередь стоит из гонщиков
за шинами, у Мандалорца — из штурмовиков за доспехами, в Головоломке —
из эмоций. Если по тексту задачи нельзя узнать вселенную, слой заполнен зря.

**Но слой мира не отменяет глагола.** «Съели», «посадили», «запасли на зиму»
задают класс предмета жёстче, чем вселенная: без фильтра по тегу выходит
«съели 108 факелов» и «посадил амулеты». Ставьте `tags` вместе с
`from_universe_items` и обязательно `fallback_lemmas` — у роботов еды не бывает,
и пул окажется пустым.


```bash

```

Правила готовят двенадцать форм, механические проверки (`tests/test_noun_dictionary_integrity.py`)
отсеивают невозможное, человек вычитывает компактную таблицу. Замеры и границы
применимости — `docs/DATA_PIPELINE.md`.

Локальная языковая модель в этой роли **измерена и отклонена**: она путает
творительный с винительным и предложный с дательным. Не возвращайте её без
нового замера.

## Отклонить задачу — нормальный результат

Причины: `non_parametric`, `search_answer`, `structured_answer`, `duplicate`,
`corrupt_source`, `needs_new_slot`. Записывается в журнал с номером и причиной.
Плохой результат — не отклонённая задача, а шаблон с кривым русским
или неверным ответом.
