# Проверенные формы персонажей

`reviewed_character_forms.json` — небольшой слой явно проверенных русских форм
персонажей из утверждённого инвентаря. Он используется только шаблонами, которым
нужны формы имени в родительном или дательном падеже либо род местоимения.

Генератор не пытается склонять составные имена эвристически: если нужной формы
нет в этом файле, такой персонаж не выбирается для соответствующей речевой роли.
Данные читает `problemgen.language.morphology.reviewed_characters`.
