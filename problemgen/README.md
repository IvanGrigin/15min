# problemgen

Python-код генератора. Здесь нет и не должно быть текстов задач: задача
описывается JSON-записью в `data/template_studio/library/`.

| Пакет | Что делает |
|---|---|
| `russian/` | морфология: парадигмы существительных и персонажей, движок слотов, реестры персонажей и вселенных, согласование с числительным |
| `template_studio/` | сэмплирование параметров, `constraints`, безопасный вычислитель выражений, валидация и публикация шаблона |
| `web/studio_site.py` | сайт пятиминуток: темы берутся из активных шаблонов |
| `core/models.py` | общие модели, используемые валидатором языка |

## Границы

- **Никакого автосклонения в рантайме.** Все словоформы заданы явно в данных.
  Правила склонения живут в `scripts/declension_rules.py` и применяются только
  при подготовке данных.
- **Никакой генерации текста в коде.** Если хочется написать f-строку с условием
  задачи — это признак, что задача должна стать JSON-записью.
- **Никакой LLM в рантайме.** Генерация детерминирована и воспроизводима по seed.

Пакеты `generation/`, `domains/`, `worksheet/`, `source_index/`, `catalog/`,
`io/`, `template_creator/` вынесены в ветку `archive/legacy-python-generators`
и не восстанавливаются — см. `../docs/ARCHIVED_LEGACY.md`.
