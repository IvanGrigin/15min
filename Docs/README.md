# Документация

Всё, что здесь лежит, соответствует одному стандарту: **задача описывается
JSON-записью, падежи и согласование берутся из данных, Python задачу решает,
но не формулирует**. Документы прошлых подходов вынесены в ветку
`archive/legacy-python-generators`.

## Порядок чтения для агента

1. **`../AGENTS.md`** — обязательные правила. Читается первым и целиком.
2. **`AGENT_TASK_TO_TEMPLATE_PROMPT.md`** — как перенести задачу корпуса
   в JSON-шаблон: 13 шагов, спецификация полей и слотов, чек-листы,
   список ловушек.
3. **`MIGRATION_LEDGER.md`** — что уже перенесено, что отклонено и почему,
   что в очереди. Обновляется после каждого батча.

## Справочники

| Файл | Когда нужен |
|---|---|
| `TEMPLATE_ARCHITECTURE_DECISION.md` | почему формат именно такой; прочитать до того, как предлагать пятый путь |
| `DATA_PIPELINE.md` | как массово добавлять существительные и персонажей; там же замеры, почему локальная модель отклонена |
| `ARCHIVED_LEGACY.md` | что закрыто и по каким причинам; **не развивать** |
| `HARVEST_FROM_LEGACY_AUDIT.md` | известные дефекты исходных задач из внешнего аудита — свериться перед переносом |

## Источники (только читать, не менять)

Корпусов три, и они согласованы между собой — это проверено по номерам задач.
Путаница здесь дорого стоит, поэтому запомните разницу:

| Путь | Что это | Задач |
|---|---|---|
| `Docs/all_tasks_all_files.md` | **полный корпус** одним файлом, сквозная нумерация 1…2121 | 2121 |
| `docs/NN_<тема>.md` (строчными!) | тот же полный корпус, разложенный по темам | 2121 |
| `Docs/NN_<тема>_*_deduplicated.md` | дедуплицированный срез по темам: `_bez_imen` и `_s_imenami` | 1145 |

Для переноса удобнее `Docs/…_deduplicated.md`: там уже убраны повторы,
а задачи-близнецы всё равно сводятся в один шаблон. Но если задачи по номеру
там нет — она не потеряна, ищите в `docs/` или в сводном файле.

| Файл | Что это |
|---|---|
| `approved_dimensions_150_characters.md` | канон 25 вселенных × 6 персонажей; сверяется тестом |
| `module_29a_regular_human_names.md` | список обычных русских имён — источник для пополнения пула `common_names.json` |
| `source_documents/` | исходный сборник задач, из которого собран корпус |

Корпус неприкосновенен: исправление формулировки исходной задачи делается
в шаблоне, а не в источнике. Если в источнике действительно ошибка —
запись об этом идёт в `MIGRATION_LEDGER.md`.

## Чего здесь больше нет

Документация 33 Python-генераторов, архива из PDF, сюжетных миров, прежнего
сайта, админки Template Studio и промпта локальной модели. Всё это описывало
подходы, от которых отказались; держать их рядом с актуальными правилами —
значит приглашать следующего агента пойти по закрытой дороге.

```bash
git show archive/legacy-python-generators:Docs/TEMPLATE_STUDIO.md
```
