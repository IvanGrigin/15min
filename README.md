# Генератор математических пятиминуток

Задача описывается **одной JSON-записью**. Python её решает и проверяет,
но не формулирует: текст условия, параметры, ограничения и формула ответа
живут в данных.

```bash
python3 run.py
```

Сайт: http://127.0.0.1:8091 — выбрать темы, число задач, собрать вариант,
распечатать. Зависимостей нет, только стандартная библиотека Python.

## Что делает генератор

Из одной записи получается бесконечно много вариантов одной задачи —
с правильными падежами, родом и согласованием:

```
Гадкий утёнок шёл первую половину пути со скоростью 10 км/ч, а потом устал
и ровно половину всего времени шёл медленнее — со скоростью 8 км/ч.
Последние 1500 метров гадкого утёнка подвезла Дюймовочка. Вся дорога заняла
2,5 часа. 1) Какой путь гадкий утёнок прошёл пешком?
2) Сколько времени гадкий утёнок ехал с Дюймовочкой?

Ответ: 1) 21,5 километра; 2) 6 минут
```

Имя склоняется («гадкого утёнка»), глагол согласуется по роду («подвезла»),
предлог выбирается по слову («с Дюймовочкой», но «со Снегурочкой»),
числительное управляет существительным («1500 метров», «2,5 часа»).

## Как устроено

| Что | Где |
|---|---|
| Шаблоны задач | `data/template_studio/library/*.json` — один файл на задачу |
| Персонажи с падежами | `data/entities/characters/` — 271 персонаж, 42 вселенные |
| Локации и предметы миров | `data/entities/universes.json` |
| Существительные | `data/language/nouns/russian_nouns.json` — 258 слов по 12 форм |
| Движок слотов | `problemgen/russian/template_engine.py` |
| Генерация и валидация | `problemgen/template_studio/` |
| Сайт | `problemgen/web/studio_site.py` |

## Добавить задачу

Положить JSON в библиотеку и опубликовать:

```bash
python3 scripts/seed_worksheet_templates.py --preview --only <template_id>
```

```bash
python3 scripts/seed_worksheet_templates.py --only <template_id>
```

Публикация прогоняет десять проверок, включая независимый пересчёт ответа
на десяти сидах. Правила и пошаговый алгоритм —
[`docs/AGENT_TASK_TO_TEMPLATE_PROMPT.md`](docs/AGENT_TASK_TO_TEMPLATE_PROMPT.md).

**Python ради новой задачи писать не нужно.** Единственный допустимый Python —
тест с независимым решателем, который решает задачу заново по её условию
и сверяет ответ.

## Добавить данные

```bash
python3 scripts/data_agent_loop.py --queue data/language/queue/nouns.json
```

```bash
python3 scripts/data_review.py
```

Правила склонения готовят все двенадцать форм, механические проверки отсеивают
невозможное, человек вычитывает компактную таблицу. Подробности и замеры —
[`docs/DATA_PIPELINE.md`](docs/DATA_PIPELINE.md).
